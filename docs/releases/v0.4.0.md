# EchoLang v0.4.0 — 让文档翻译真正可用

这一版围绕一个目标重做：让论文、报告与长文档从“能够调用模型”走向“能够稳定完成、舒服阅读并正式交付”。

![EchoLang 中英对照阅读工作台](https://raw.githubusercontent.com/Mu-scorpio/EchoLang/v0.4.0/docs/screenshots/echolang-reader.png)

## 这次更新带来了什么

- 重构 DOCX 解析流程，增强双栏阅读顺序、意外断行、表格、图片与公式处理。
- 图片和公式只跳过翻译，不再从阅读结果消失；导出时会恢复到对应位置。
- 重做 DOCX / PDF 导出排版，移除内部段落编号、请求序号和解析诊断信息。
- 阅读与批量翻译使用独立列表，并支持拖动调整侧栏宽度。
- 单段失败不会中断全文：自动重试，耗尽后暂时跳过，其余段落继续翻译。
- 进度统一为“已翻译段落 / 总段落”，并根据当前平均耗时估算剩余时间。
- 请求按钮绑定真实运行状态，清晰区分翻译、停止、继续和重新翻译。
- 重做供应商拖拽排序、卡片层级、模型右键测试与模型级请求设置。
- 新增模型推理强度：关闭（默认）、Low、Medium、High、XHigh、Max。
- 新增五套浅色配色、可调阅读排版，以及参考 GitHub Dark 的深色模式。
- 修复 `start.bat` 偶尔重复启动两套服务、导致配置数据不一致的问题。

## 下载哪个文件

| 文件 | 用途 |
| --- | --- |
| `EchoLang-0.4.0-portable.exe` | Windows 便携版，下载后直接运行。 |
| `EchoLang-0.4.0-setup.msi` | Windows 安装包，创建开始菜单与桌面快捷方式。 |
| `EchoLang-0.4.0-web-source.zip` | 可部署的 Node.js Web 源码包。 |
| `SHA256SUMS.txt` | 用于验证上述文件是否完整。 |

> Windows 二进制目前未使用商业代码签名证书。若 SmartScreen 提示未知发布者，请确认下载地址属于本仓库，并对照 `SHA256SUMS.txt` 校验文件。

## 运行要求

- Windows 桌面版：Windows 10/11 x64，无需另装 Node.js。
- Web 源码版：Node.js 20 或更高版本。
- 翻译服务：需要用户自行配置受支持供应商的 API Key。

完整功能说明、截图和部署方式请阅读 [README](https://github.com/Mu-scorpio/EchoLang#readme)，所有变更见 [CHANGELOG](https://github.com/Mu-scorpio/EchoLang/blob/v0.4.0/CHANGELOG.md)。
